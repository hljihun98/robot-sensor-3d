로봇 센서 파손 이력, 두 가지 구현

같은 기획안으로 만든 두 프로그램입니다. 라이다 2개·카메라 2개를 3D로 보고, 파손을 신고·승인·이력으로 관리합니다.

런처가 꺼졌습니다. 실행 중이던 프로그램도 함께 꺼졌을 수 있습니다. START.cmd(또는 npm start)를 다시 실행하면 이 화면이 자동으로 다시 연결됩니다.

내 PC에서 실행하기

따로 설치할 프로그램 없이 폴더 하나로 실행됩니다. 처음 실행할 때 필요한 패키지를 자동으로 받습니다(인터넷 필요).

  1. Node.js 설치

    Node.js 24 이상(LTS)을 설치합니다. damage만 쓸 때는 22.13 이상이면 됩니다.

    Node.js 내려받기

  2. 코드 받기

    방법 1 · ZIP 파일

    내려받아 원하는 곳에 압축을 풉니다. robot-sensor-3d-main 폴더가 생깁니다.

    ZIP 내려받기
    방법 2 · Git 
    git clone https://github.com/hljihun98/robot-sensor-3d.git
cd robot-sensor-3d

  3. 런처 실행

    폴더 안의 START.cmd를 더블클릭합니다. 검은 창이 뜨고 브라우저가 자동으로 열립니다. 이 창을 닫으면 모든 프로그램이 꺼집니다.

    보안 경고 창이 뜨면 실행(또는 추가 정보 → 실행)을 누르세요.

    터미널에서 폴더로 이동해 실행합니다. 브라우저가 자동으로 열립니다.

    ./start.sh

    또는 npm start

  4. 프로그램 실행

    이 홈페이지가 http://127.0.0.1:8080 주소로 열리면, 쓰고 싶은 프로그램의 실행을 누르고 준비되면 열기를 누릅니다.

    런처 열기 런처를 켠 뒤에 누르세요.

자주 묻는 질문

실행을 눌렀는데 오래 걸려요.

처음 실행할 때만 필요한 패키지를 인터넷에서 받습니다. 카드에 진행률이 나오며 인터넷 속도에 따라 몇 분 걸릴 수 있습니다. 두 번째부터는 몇 초 안에 켜집니다.

"포트를 다른 프로그램이 쓰고 있습니다"라고 나와요.

같은 프로그램이 다른 창에서 이미 켜져 있는 경우가 많습니다. 카드의 열기로 그대로 쓰거나, 그 창을 닫은 뒤 다시 실행을 누르세요.

첫 로그인 비밀번호를 모르겠어요.

센서로그는 카드에 계정이 나오며, robot-sensor-platform/data/initial-account.txt에도 있습니다.

센서 파손 3D 이력관리(서버 모드)는 처음 실행할 때 한 번만 카드에 나옵니다. 놓쳤다면 런처를 끄고 robot-sensor-damage 폴더에서 npm run seed -- --reset을 실행하세요. 기존 데이터는 백업 파일로 옮겨지고, 새 임시 비밀번호가 터미널에 나옵니다.

휴대폰이나 다른 PC에서 접속하고 싶어요.

런처는 보안을 위해 이 PC 안에서만 열립니다. 여러 사람이 쓰려면 서버에 올리고 HTTPS를 설정해야 합니다. 각 폴더 README의 서버 운영 방법을 보세요.

데모 데이터를 처음 상태로 되돌리고 싶어요.

데모 화면 맨 위의 데모 초기화를 누르세요. 데이터는 그 브라우저에만 있어서 다른 사람에게는 영향이 없습니다.

"Node.js 24 이상이 필요합니다"라고 나와요.

nodejs.org에서 LTS 버전을 설치한 뒤 런처 창을 닫고 다시 실행하세요. damage의 데모 모드는 낮은 버전에서도 실행됩니다.

각 프로그램의 자세한 설명은 폴더의 README를 보세요. GitHub 저장소
