센서 3D 이력관리실행 관리 연결 확인 중…

로봇 센서 파손 이력, 두 가지 구현

같은 기획안으로 만든 두 프로그램입니다. 라이다 2개·카메라 2개를 3D로 보고, 파손을 신고·승인·이력으로 관리합니다.

내 PC에서 실행하기

이 홈페이지를 내 PC에서 띄우면 버튼으로 두 프로그램을 실행·중지할 수 있습니다. 처음 실행할 때 필요한 패키지를 자동으로 설치합니다(인터넷 필요).

  1. Node.js 24 이상을 설치합니다. (damage만 쓸 때는 22.13 이상)
  2. 코드를 받습니다. 
    git clone https://github.com/hljihun98/robot-sensor-3d.git
cd robot-sensor-3d
  3. Windows는 START.cmd를 더블클릭, 그 밖에는 터미널에서 npm start.
  4. 브라우저에서 http://127.0.0.1:8080 이 열리면 원하는 프로그램의 실행을 누릅니다.
